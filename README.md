# 台股交易研究室

**線上版：https://stock-system-kn5v.onrender.com**（免費主機，閒置後首次開啟需等候約 30–60 秒）

自動化台股交易研究網站，包含 7 個模組。每個模組都由量化引擎計算（技術指標、回測、風險模型），設定 Claude API 金鑰後會再加上 AI 深度解讀。

## 啟動

```bash
npm install
npm start
```

開啟 http://localhost:3000

### 啟用 Claude AI 解讀（選用）

```powershell
$env:ANTHROPIC_API_KEY = "sk-ant-..."
npm start
```

預設模型為 `claude-opus-5-5`，可用 `CLAUDE_MODEL` 環境變數更換。未設定金鑰時，所有量化分析仍可正常使用。

## 部署到 Render（取得公開網址）

1. 以 GitHub 帳號登入 [Render](https://render.com)
2. 選擇 **New → Blueprint**，連結本儲存庫，Render 會讀取 `render.yaml` 自動建立服務
3. 部署完成後取得 `https://stock-system-xxxx.onrender.com` 網址

免費方案閒置 15 分鐘後會休眠，再次開啟需等候約 30–60 秒。若要啟用 AI 解讀，請在 Render 的 Environment 頁面新增 `ANTHROPIC_API_KEY`（公開網站的所有訪客都會使用此金鑰額度）。

## 新手模式（首頁）

輸入「資金」與「風險承受度」，系統會：
1. 判斷大盤現在能不能買（偏多／盤整／偏弱；偏弱時只給觀察名單，不給買進股數）
2. 從股本前 60 大公司篩選：走勢向上、不過熱、價格不貴、波動不大、停損幅度 ≤ 8%，並排除近期負面新聞偏多者
3. 為每檔計算買進價、買幾股、停損價、目標價、最壞虧損與預期獲利（每筆風險 ≤ 資金 0.5%／1%／2%，單檔 ≤ 20%／25%／30%，總投入 ≤ 80%）
4. 附上 ETF 清單、新手五大守則與白話名詞解釋

## 模組

| # | 模組 | 輸入 | 輸出 |
|---|------|------|------|
| 1 | 交易點子生成器 | 產業（半導體）、指數（加權指數／櫃買）或代號清單 | 5 組機會：進場區間、目標、停損、風報比、**該股歷史同型態勝率**、技術面與基本面理由 |
| 2 | 自動化技術分析 | 代號／名稱 | 日線與週線評分、支撐壓力、趨勢線、均線、RSI/MACD/KD/ADX、6 步驟訊號與 K 線圖 |
| 3 | 新聞轉交易策略 | 公司或產業 | 30 天新聞情緒與主題、短期／長期影響、1σ 價格區間、依風險預算計算的部位 |
| 4 | 策略回測分析 | 標的 + 策略 + 期間 | 勝率、獲利因子、最大回撤、夏普值、權益曲線、樣本內外檢驗、自動測試的改進變體 |
| 5 | 投資組合風險管理 | `2330 40%, 2317 20%…` + 風險屬性 | 波動、Beta、VaR、風險貢獻、相關矩陣、隱藏相關性、平衡方案、大盤跌 20% 避險（小台／TXO／00632R） |
| 6 | 交易日誌分析 | 每行：`進場日,代號,多/空,進場價,出場日,出場價,股數,停損價,備註` | 錯誤、行為偏誤（處分效應、報復性交易、過度自信、追高）、錯失機會、3 條個人化規則 |
| 7 | 全自動交易計畫 | 台股／台指期／個股 | 含時間標記的檢查清單（07:30 → 21:00），可勾選並保存進度 |

回測策略：均線交叉、RSI 超買超賣、RSI 背離、MACD 交叉、KD 交叉、布林通道均值回歸、通道突破（海龜）。

## 架構

```
server.js          Express API
lib/data.js        Yahoo Finance K 線、TWSE/TPEx 開放資料（本益比、殖利率、產業）、Google 新聞 RSS、快取
lib/indicators.js  MA/EMA/RSI/MACD/KD/ATR/布林/ADX、擺盪點、支撐壓力、趨勢線、背離
lib/analysis.js    模組 2      lib/ideas.js     模組 1
lib/news.js        模組 3      lib/backtest.js  模組 4
lib/portfolio.js   模組 5      lib/journal.js   模組 6
lib/plan.js        模組 7      lib/ai.js        Claude API（串流 + 拒答時自動切換備援模型）
public/            前端（紅漲綠跌、lightweight-charts）
```

## 注意事項

- 資料來源為免費公開資料，報價可能有延遲；Google 新聞 RSS 僅限個人研究使用。
- 回測假設：收盤產生訊號、次日開盤成交，手續費 0.1425%×6 折，證交稅 0.3%（ETF 0.1%），不含滑價與除權息調整。
- 本系統為研究輔助工具，所有輸出皆**不構成投資建議**，交易決策與風險請自行承擔。
